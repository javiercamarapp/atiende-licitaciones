**Escala estricta de Estado** (una de las seis, sin intermedios):
- **PENDIENTE**: sin código que lo implemente.
- **EN_EVIDENCIA**: código + test en verde, auditado o no, pero sin reverificación cerrada, o con hallazgo abierto que lo afecta, o con nota "mock"/"fixture" si la integración real no está verificada.
- **CUMPLIDO**: código + test + auditoría con hallazgos corregidos **y** reverificación independiente con veredicto CERRADO explícito para los hallazgos que lo afectan, sin PARCIAL/NO CERRADO relacionado.
- **BLOQUEADO_EXTERNO**: depende de credenciales/acceso externo no disponible (ComprasMX reCAPTCHA B-02, OpenAI real, Postgres productivo/CI B-03, validación por abogado externo).
- **NO_APLICA_A_PAQUETE**: el requisito no aplica al paquete listado como "dueño natural"; se anota el paquete correcto o la naturaleza (decisión reservada, revisión legal humana, decisión de producto).
- **LÍMITE_ACEPTADO**: hallazgo residual de severidad ≤MEDIA, documentado con causa, tras la "regla de 3 vueltas" de corrección (Likida) — no se abre una cuarta vuelta; se cita el informe donde se aceptó el límite.

Ningún criterio se marca CUMPLIDO por un mock, fixture, o integración simulada; las integraciones reales no verificadas son BLOQUEADO_EXTERNO o EN_EVIDENCIA con nota "mock".
